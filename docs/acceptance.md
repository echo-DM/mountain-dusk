## 环境与结果

本地 Vite 页面，桌面 Chromium 浏览器；桌面画幅 1440 × 1000，模拟手机画幅 390 × 844。手机画幅检查不代表真实手机设备或跨浏览器验证。

- TypeScript 类型检查与 Vite 生产构建通过。
- 生产预览页面的八句切换及返回全景均通过，最终浏览器未报告运行错误。
- 八句诗均可选中，镜头完成后与对应景观一致，当前诗句只有一个选中项。
- 全景及八个诗句镜头均已实际截图检查；竹径、荷塘与秋草近景的前景遮挡已修正。
- 快速连续选择清泉、山居、竹径后，镜头正确落在最后选择的竹径。
- 实际鼠标拖动可以环顾，返回全景可以恢复初始构图；动画暂停按钮更新状态。
- 模拟手机画幅无横向溢出，八个诗句入口完整显示，荷塘镜头可正常切换。
- 模拟 `prefers-reduced-motion: reduce` 时默认暂停景物动画，选择诗句直接到达目标镜头。
- 使用 `WEBGL_lose_context` 模拟图形连接中断：显示重新加载提示、停止交互，八句诗文仍完整保留。
